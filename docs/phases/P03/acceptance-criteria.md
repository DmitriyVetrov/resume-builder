# Acceptance Criteria

A clean checkout can build/test; backend/frontend jobs independent; integration job runs contract checks.

List requirement IDs and observable pass/fail criteria.

Written by the Solution Architect, 2026-11-02. Plan: `architecture/phase-plan.md` (section numbers below refer to it). Decisions: `decisions.md`, ADR-041, ADR-042. The positive and negative cases are the oracle for the Test Architect. Where the negative column says "—", the criterion is a review or handoff-check item (kickoff §3).

| ID | Pri | Source | Criterion (observable) | Positive case | Negative case |
|---|---|---|---|---|---|
| AC-P03-01 | Must | ADR-004, ADR-009, ADR-034, NFR-10; §4 | With no `.env` file, `docker compose up -d --wait` brings `mongo`, `azurite` and `mailpit` to healthy within 120 s on a warm cache, and `docker compose down -v` removes containers, network and volumes. Behaviour checks: MongoDB reports replica set `rs0` with this node PRIMARY, and a `w: majority` insert is acknowledged; Mailpit accepts an SMTP message on its SMTP port and lists it through its HTTP API; Azurite answers on the Blob port | smoke in the integration job on a separate Compose project (DD-P03-20) | a mutated Compose model in which one service has no healthcheck fails the static check; a smoke against MongoDB without the replica set initiated fails the replica-set assertion |
| AC-P03-02 | Must | T-TA-06, T-EP-05; §4 | Compose hygiene: every image is `repo:tag@sha256:<64 hex>` and equal to its `infrastructure/images.lock` entry; every published port binds `127.0.0.1`; data services use named volumes; one explicit network; no `privileged`, no host network, no Docker socket mount; no credential-like environment values; telemetry/version-check opt-outs set for Azurite and Mailpit | static check over `docker compose config --format json` | one mutation per rule (tag without digest, digest ≠ lock, `0.0.0.0` or no host IP, `privileged: true`, a password-like env value) each fails |
| AC-P03-03 | Must | rule 03, T-ID-10; §7 | Env conventions: `.env.example` exists and holds only loopback endpoints, `UseDevelopmentStorage=true` and placeholders; `.env` and `.env.local` are git-ignored (`git check-ignore`); Compose resolves with no `.env` present | static check + `git check-ignore` | a temp copy of `.env.example` with a secret-like value (for example `AccountKey=` + base64, or a non-loopback host with a password) fails; a `.gitignore` without the `.env` rule fails the ignore check |
| AC-P03-04 | Must | ADR-002, ADR-041, DoD; §5.1, §8.1 | `scripts/ci/backend.sh` exits 0: locked restore, Release build with warnings as errors, `dotnet format --verify-no-changes`, and tests on `net10.0`, including the xUnit v3 canary and the Testcontainers MongoDB replica-set `w: majority` canary (pinned image). Packages are versioned centrally with exact versions and lock files | run the script | a canary that fails makes the script exit non-zero; a `packages.lock.json` that does not match `Directory.Packages.props` (temp copy) makes `--locked-mode` restore fail |
| AC-P03-05 | Must | ADR-003, ADR-041, DoD; §5.1, §8.2 | `scripts/ci/frontend.sh` exits 0: `npm ci --ignore-scripts`, `lint`, `typecheck` (with `strict`, `noUncheckedIndexedAccess` and `exactOptionalPropertyTypes` all on), the Vitest + RTL canary, and `build`. All `package.json` versions are exact | run the script; static check of the tsconfig flags and exact versions | a temp copy with a type error, or a failing canary assertion, makes the script exit non-zero; a tsconfig without one of the three flags, or a `^`/`~` version, fails the static check |
| AC-P03-06 | Must | ADR-041, ADR-010 G3/G7 basis; §8.3 | `scripts/ci/e2e.sh` exits 0: the built SPA is served on loopback and the Playwright smoke passes in Chromium, Firefox and WebKit inside the digest-pinned Playwright image. `@playwright/test` is pinned exactly to the image version. The page makes no request outside `127.0.0.1` | run the script | a failing assertion makes the script exit non-zero; a request to a non-loopback host fails the smoke; a mismatch between the package version and the image tag fails the static check |
| AC-P03-07 | Must | DoD, P03-OBL-01; §5.1 | `scripts/ci/integration.sh` runs the three `docs/phases/P02/tests/suite.cmd` commands unchanged, including oasdiff against `main`, then the Compose smoke (AC-P03-01). It exits 0, and it exits non-zero if any of them fails. It works when no local `main` branch exists but `origin/main` does | run the script; static check that the three commands come from `suite.cmd` and that the script uses `set -euo pipefail` | the script run with a failing stand-in for one contract command exits non-zero; a clone without a local `main` still finds the baseline, and a clone with no `main` reference at all fails with a clear message |
| AC-P03-08 | Must | DoD "jobs independent"; §5.2 | The workflow has the jobs `backend`, `frontend`, `e2e`, `integration` and `security`. Each has exactly one `run:` step calling `scripts/ci/<job>.sh`. `backend` and `frontend` have no `needs:` and do not call each other's scripts. Each of `local.sh backend` and `local.sh frontend` passes alone on a clean checkout | static check + two isolated runs | a mutated workflow with `needs: backend` on `frontend`, or with an extra inline `run:`, fails |
| AC-P03-09 | Must | T-EP-06, T-TA-06; §5.2 | Workflow hardening: top-level `permissions: contents: read`; no `write` permission anywhere; no `pull_request_target`; no `secrets.` reference; every `uses:` is pinned to a 40-hex SHA with a version comment; every `actions/checkout` has `persist-credentials: false`; every job has `timeout-minutes`; actionlint passes | static check + actionlint | one mutation per rule (tag-pinned `uses:`, `contents: write`, `pull_request_target`, a `secrets.X` reference, missing `persist-credentials: false`) each fails |
| AC-P03-10 | Must | T-ID-10, rule 03; §6 | Secret scan: gitleaks (digest-pinned) finds nothing in the working tree or the git history, and the handoff-check secret rule passes. `.gitleaks.toml` has no blanket allowlist | `security.sh` | gitleaks run on a temp directory holding a planted fake credential that matches a default rule (generated at test time, never committed) exits non-zero |
| AC-P03-11 | Must | T-TA-06, P03-OBL-02; §5.3, §6 | Dependency scan: OSV-Scanner (digest-pinned) covers `frontend/package-lock.json`, `tests/contract/package-lock.json`, `tests/e2e/package-lock.json` and every `backend/**/packages.lock.json`, with no un-waived finding. Waivers have an ID, reason and expiry. `.github/dependabot.yml` covers npm (3 directories), NuGet, GitHub Actions and the Compose images. Every npm install in `scripts/ci` uses `--ignore-scripts` | `security.sh`; static checks | a temp lockfile containing a package version with a published advisory is reported (non-zero); a Dependabot file missing one ecosystem or directory fails; an `npm ci` without `--ignore-scripts` in a script fails the static check |
| AC-P03-12 | Must | ADR-033 "same pipeline runs locally"; §5.1 | `scripts/ci/local.sh` runs preflight and all five jobs from any current directory and prints one result line per job. It exits 0 on the phase head. `local.sh <job>` runs only that job. A failed job does not stop the remaining jobs, but the final exit code is non-zero | run the script | a run with a job forced to fail (for example an unknown job name, or a stub job through a test hook) exits non-zero and still reports the other jobs |
| AC-P03-13 | Must | DoD "clean checkout can build/test"; PD-P03-03 | From a fresh checkout (a copy of the `git ls-files -co --exclude-standard` files before the commit, a `git clone` after it), with only the prerequisites documented in `infrastructure/README.md`, `scripts/ci/local.sh` exits 0. `scripts/ci/preflight.sh` exits 0 on the reference machine | QA run (once) | `preflight.sh` with a `PATH` that hides `dotnet`, or a stub reporting the wrong Node major, exits non-zero and names the tool |
| AC-P03-14 | Must | ADR-041; register | ADR-041 is Accepted and listed in the register. The backend, frontend and E2E canaries use exactly the ADR-041 tools. No rejected tool (FluentAssertions, Moq, Jest, Cypress) appears in any manifest | static check over manifests | a temp manifest containing a rejected package fails |
| AC-P03-15 | Must | NFR-09, ADR-040 §Security; §5.1 | Privacy: every script sets the telemetry opt-outs (`DOTNET_CLI_TELEMETRY_OPTOUT=1`, `REDOCLY_TELEMETRY=off`, and the Azurite and Mailpit opt-outs in Compose). Fixtures are fictional | static check + review | a temp script copy without `DOTNET_CLI_TELEMETRY_OPTOUT` fails the static check |
