# Acceptance Criteria — P00

Definition of Done (`PHASE.md`): "Cannot be closed until FR/NFR and exclusions are mapped; open decisions have an owner/deadline."

Formats, vocabularies and rules referenced below are defined in `architecture/phase-plan.md` §7 (cited as "plan §7.x").
All criteria are **Must**. Verification types:
- **auto**: an executable check in `docs/phases/P00/tests/`.
- **review**: Code Reviewer and QA judgement with a written finding.
- **gate**: QA and owner at the P00 gate.

The auto checks must derive their expected values from the source files (spec, register, PHASE.md, TRACEABILITY.md) and from the
seed list in plan §7.7. They must not hard-code answers.

DoD mapping: "FR/NFR … mapped" → AC-P00-07…11. "exclusions … mapped" → AC-P00-12, 13. "open decisions have
owner/deadline" → AC-P00-14…20. The baseline, scope and integrity criteria (AC-P00-01…06, 21…25) support these.
