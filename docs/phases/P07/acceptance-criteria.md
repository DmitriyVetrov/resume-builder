# P07 Acceptance Criteria

Each criterion is observable and pass/fail. "Must" fails the gate. Executable mapping: [tests/test-plan.md](tests/test-plan.md).

| ID | Pri | Source | Observable criterion |
|---|---|---|---|
| AC-P07-01 | Must | §10.1, §10.2, FR-HDR-01…05, FR-SEC-02…11, FR-TYP-01…03, R-2…R-8, R-13, R-14 | Every contract document example round-trips JSON-equal. Any section type combination, several of one type, any order, all-empty fields and hidden sections save unchanged and in order. `start > end` saves with a `date_range_inverted` warning. Closed-schema violations (unknown property, wrong type, content not matching type, inline with ≠ 1 paragraph, nested list, bad enum, bad date, disallowed URL scheme) answer 400 `validation_failed` with `location`, `pointer` and `code`. |
| AC-P07-02 | Must | NFR-12, domain-model §6 | At the limit passes and one over fails, for: 200 resumes active + trashed (409 `limit_reached`, also under parallel creates), 100 sections, 100 entries, 100 list items, 20 contacts, 50 000 code points (emoji counts 1), field lengths, 1 MB body, depth 64. |
| AC-P07-03 | Must | FR-LIB-01, NFR-02 | `listResumes` returns only summaries, newest first with `id` tie-break, with stable cursor paging and 400 on a bad `limit`, `state` or `cursor` (including another user's). The library shows title, template placeholder, last modified, loading, empty and recoverable error states. Real first-page thumbnails are P11 (DD-P07-15). |
| AC-P07-04 | Must | FR-LIB-02, FR-SEC-01 | Blank create yields the FR-SEC-01 set in order, T1, accent 0, default layout, and is accepted by the real API. Copy duplicates document, layout, order and photo under new resume and photo IDs at version 1, with an independent photo lifecycle. Copying a trashed source is 409, a foreign one 404. |
| AC-P07-05 | Must | FR-LIB-03 | Rename changes only the title, up to 150 code points, through `replaceResumeDocument` with `If-Match`; over-length is rejected before any request; a stale version reports a recoverable message. |
| AC-P07-06 | Must | FR-LIB-04, ADR-016, R-10 | Delete asks for confirmation and moves to trash (`deletedAt`, `purgeAt` = +30 days, version +1). Trash lists by `deletedAt` with days left. Restore and permanent delete work with `If-Match`. Trashed resumes are readable, all writes answer 409. Trash and restore answer 409 in the wrong state. |
| AC-P07-07 | Must | FR-LIB-05 | Each card opens `/resumes/{id}/edit`; `getResume` returns the document with `ETag` and `no-store`, including for trashed resumes. |
| AC-P07-08 | Must | ADR-037, FR-PER-03, NFR-10, T-TA-01 | Missing `If-Match` 428; `*`, list or weak tag 400 with `location: header`; stale 412 with `currentVersion`, `updatedAt` and no content. Every write increments the version by exactly 1. Parallel writers with one version: exactly one 200, the rest 412. Writes use majority and journal write concern. |
| AC-P07-09 | Must | ADR-037 §3, T-TA-07, BE-P02-11 | Missing key 400. Same key and body replays the original status, `ETag`, `Location`; a document replay returns the stored version and warnings and writes nothing. Same key with a different body is 422 and nothing changes. In-flight duplicate of a keyed create is 409 with `Retry-After`. Multipart retry with a new boundary replays. A crash between effect and completion does not duplicate or double-apply. Keys are owner-scoped. |
| AC-P07-10 | Must | NFR-08, R-1, T-EP-01/02/03, T-ID-02 | For all 15 operations: anonymous 401; another user's IDs 404 with A's data unchanged; each unsafe one without CSRF 403. No request can set a server-owned field. |
| AC-P07-11 | Must | FR-PHO-01…05, FR-LIB-02, ADR-009, T-TA-04, T-ID-04 | JPEG, PNG and WebP upload by magic bytes, declared type ignored; others 415. Undecodable, > 8000 px or > 40 MP is 400 `photo_invalid`. Over 5 MB file or 6 MB body is 413. EXIF and GPS are absent from master and rendition, orientation is applied, trailing polyglot bytes are gone. Default crop is the largest centred square; crop updates regenerate the rendition only; non-square and out-of-bounds crops are rejected. GETs carry `private, no-cache`, a byte `ETag`, `nosniff` and answer 304; they work when trashed. Replace and remove leave no blobs behind. |
| AC-P07-12 | Should | FR-PER-05, ADR-037 §7 | Automatic snapshots at most every 10 minutes of writes; `before_export` creates once per version (201, then 200) and does not change the version; list and get are owner-scoped and ordered; `expiresAt` is +30 days. |
| AC-P07-13 | Must | ADR-039 §2–§3, FR-ACC-03/04, T-DS-03, T-ID-09 | Permanent delete and photo removal or replacement write a Mongo and a Blob ledger entry before any deletion, IDs only; a failed ledger write deletes nothing and is retried to completion. Account purge removes resumes, trash, snapshots, photos and idempotency records. `exportAccountData` returns the owner's active and trashed resumes and nothing of anyone else's. |
| AC-P07-14 | Must | Contract, rule 02 | The host route inventory equals the contract's P04, P06 and P07 operations with their statuses. Responses validate against the contract schemas, errors are RFC 9457 with `traceId`, `git diff main...HEAD -- contracts` is empty. |
| AC-P07-15 | Must | NFR-08, NFR-13, T-ID-05 | A canary placed in every document field, a filename and a key name appears in no log line and no Problem body. Stored ledger entries and blob keys contain no user text. |
| AC-P07-16 | Must | ADR-038, T-DS-02/03 | `doc-write` over 120/min per user and `photo-upload` over 20/h per user answer 429 with `Retry-After`; another user is unaffected. |
| AC-P07-17 | Must | UI-UX-DESIGN, [ui-ux-design.md](architecture/ui-ux-design.md) | Library, trash and dialogs match the design at 1280, 1024 and 390 px with no horizontal page overflow, also at the 640 px zoom proxy and at real 200% zoom. No excluded feature or sample content appears. No third-party request. |
| AC-P07-18 | Must | NFR-06 | Keyboard-only create, rename, delete, restore and purge work. Dialogs trap focus, start on the safe action, and return focus. Axe reports no WCAG 2.1 A/AA violation on idle, empty, error, trash and dialog states. Status is announced. Contrast is measured on real surfaces. Reduced motion removes transitions. |
| AC-P07-19 | Must | D-05, D-06, D-11, charter gate policy | ADR-017 and ADR-018 are Accepted before implementation, the register reflects them, and the behaviour matches them: no wizard, no sample content, default labels for Education. |
| AC-P07-20 | Must | NFR-07 | Spanish, Ukrainian, Slovak and emoji text round-trips exactly through create, read, snapshot, copy and the library card. |
