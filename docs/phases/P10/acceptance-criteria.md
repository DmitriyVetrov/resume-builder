# P10 Acceptance Criteria

Observable criteria. "Draft" is the labelled draft view of DD-P10-02; page-accurate clauses are named and stay with P11 or P12.

| ID | Source | Pass when |
|---|---|---|
| AC-P10-01 | ADR-010 §6, ADR-041 | G1, G3, G5, G6, G7 and G2 in Chromium meet their targets on the recorded runner, or the ADR's fallback path was followed and re-measured. The outcome is an ADR-010 "Technology confirmation" amendment. Recorded alongside: bundle size, fonts size, runner, and which G3/G4 evidence is not from the reference CI runner. |
| AC-P10-02 | FR-TPL-01, FR-TPL-05, D-12 | T1 (default), T2 and T3 exist as data definitions with no import from the document or React. A fourth definition, added in a test, resolves with no change to the content model. |
| AC-P10-03 | FR-TPL-02, FR-EDT-05 | The Design tab holds the picker: three thumbnails showing the user's own text, updating after an edit. The selected one is marked in a way that is not colour alone. It is a keyboard-operable radio group. |
| AC-P10-04 | FR-TPL-03, FR-TPL-04 | A switch changes only `templateId`. T1 → T2 → T3 → T1 gives a deep-equal document, an identical draft DOM and an identical PageModel hash. Section order in the draft equals document order for every template; T3 keeps document order within each column. |
| AC-P10-05 | D-13, ADR-025 | With T3 active, `list` and `inline` default to the sidebar, `text` and `entries` to main; the Design tab overrides per section. T1 and T2 ignore the field and keep it. |
| AC-P10-06 | FR-CLR-01…04, D-14 | Each template offers exactly three swatches with a check on the selected one. T1 is `#2A68A0`, `#335776`, `#333333`. Every preset of every template is ≥ 4.5:1 against white. Changing colour repaints exactly the §6.2 / ADR-024 roles and leaves body text near-black. No free picker or hex input exists. |
| AC-P10-07 | FR-LAY-01, D-15, SC-06 | Small, Medium and Large give the sizes of §6.9 by the ADR-027 rule. Every text style changes; spacing values, markers, rules and the photo do not. |
| AC-P10-08 | FR-LAY-02…04, D-16, SC-03, §5.10 | Sliders run 0–20 with the value visible; arrows ±1, Home and End, double-click resets to default. In the resolved design and the PageModel: space above a section title `10 + v`, between entries `v`, line height `round(size × 1.2) + v × 0.5`. **PDF measurement within ±0.5 pt: P12.** |
| AC-P10-09 | FR-LAY-05, FR-LAY-06, SC-04 | A4 (default) and US Letter change the sheet's proportions and the PageModel's geometry (595×842, 612×792). Narrow 16, Normal 23, Wide 36 and custom 10–50 apply to all four sides; the continuation-page top is margin + 8 pt in the PageModel. Invalid custom text never reaches the document. |
| AC-P10-10 | FR-LAY-07, FR-PER-04 | Reset design restores FR-LAY-01…06, every `listColumns` and the colour to the active template's defaults, and leaves font, language, date format, placement and content alone. One Undo restores all of it. |
| AC-P10-11 | FR-LAY-08, NFR-07, NFR-14 | Each template offers three fonts, served from our own origin and rendered in the draft. All faces cover the Spanish, Slovak and Ukrainian test strings. An unknown or foreign `bodyFont` resolves to the template default without being rewritten. Licences are committed with the fonts. |
| AC-P10-12 | FR-LAY-09, §5.6 | Language (en, es, uk) changes month names and the "Present" label, and the four date formats apply, in the draft and in the engine, from one pure function with no `Intl`. A date text override wins. **Hyphenation: P11 (DD-P10-11).** |
| AC-P10-13 | FR-LAY-10, FR-PER-04 | Every control changes the draft at once, reaches the PUT body through the autosave queue and survives a reload. Each is one undo step; a slider drag or held arrow coalesces into one. **NFR-01 latency as a release target: P11 (the G3 gate is measured here).** |
| AC-P10-14 | FR-SEC-11, SC-05 | Null `listColumns` resolves by type and template (T1: `list` 2, `entries` 2, `text` 1; T2 and T3 per ADR-024). An explicit 1 or 2 wins. The draft and the PageModel apply it; the TXT serializer ignores it. |
| AC-P10-15 | FR-HDR-05, FR-HDR-06, §6.3, §7 | T1 shows no icons, T2 shows one per contact kind, T3 none. The photo is rounded-square left in T1, absent in T2 (`showPhoto` untouched), round in the band in T3. Without a photo the text column takes the full width. |
| AC-P10-16 | §6.1–§6.9, D-18, D-19 | T1 tokens are as §6 with the recorded decisions: name, section titles, organization, markers, separators and timeline dots use the accent; links use the accent with no underline (a user's own underline stays); Education uses the same block as Experience; no separator at a line start in the PageModel; a single-entry section draws no timeline line. |
| AC-P10-17 | NFR-06 | Every control is reachable and operable by keyboard with a visible focus and an accessible name; axe (WCAG 2.1 AA tags) finds nothing on the Design tab for each template in three browsers; at 390 px and at 200% zoom nothing is clipped and no horizontal page scroll appears; `prefers-reduced-motion` removes transitions. |
| AC-P10-18 | §3.2, NFR-09, FR-CLR-04 | No excluded feature is built. No font or other request leaves our origin (checked in E2E). The contract is unchanged (`git diff main -- contracts` empty). Existing P08 and P09 tests still pass, unedited. |
| AC-P10-19 | Required test strategy | Chromium visual baselines of the draft sheet for T1, T2 and T3 pass in the pinned image from a synthetic fixture with Spanish and Ukrainian text. |
