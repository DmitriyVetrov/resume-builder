| DD-P10-14 (`DELEGATED-DEFAULT`) | ADR-010 G2 asks for "≤ 1% pixels at 100 dpi" and does not define a differing pixel. An exact comparison scored 2–5% on pages that line up. Browsers snap a text baseline to a whole device pixel and poppler does not, and any two rasterisers antialias differently. Options: (a) exact comparison, which cannot pass in any painter, (b) a raised percentage, which would also hide real shifts, (c) keep 1% and define a pixel as differing when nothing within one device pixel of it in the other image is within 76 of 255 per channel. | **(c).** It measures layout, not rounding, and leaves the 1% limit as written. `raster-diff.mjs` carries a negative control in the same run: the same page shifted 3 px (about 2 pt) must score above 1%, or G2 fails. Chromium's project also disables LCD text, whose coloured fringes a PDF raster cannot have. | ADR-010 §6 G2, FR-PRV-02 |
| DD-P10-15 (`DELEGATED-DEFAULT`) | G1 found Latin `M` missing from the text of a PDF written after another document containing Cyrillic `М`. PDFKit's subsetter creates fontkit glyphs for composite parts with no code points, and fontkit caches them on the `Font`, so a shared instance loses the letter from every later ToUnicode map. Options: (a) one parsed `Font` per PDF, (b) patch PDFKit, (c) write the ToUnicode map ourselves. | **(a).** `writePdf` registers the font file and PDFKit parses its own instance. It costs one parse per export, and a user who exports twice would otherwise get an unsearchable PDF. The G1 run proves it: the fixtures run in sequence on one `FontBook`. | FR-PDF-02, ADR-010 §7 |
| DD-P10-16 (`DELEGATED-DEFAULT`), refines DD-P10-13 | The static policy test fixes five CI jobs of one `run:` line each. | The rendering suite runs at the end of `scripts/ci/e2e.sh`, the path DD-P10-13 named as the fallback. `local.sh` is unchanged, so `rendering.sh` is run directly or through `local.sh e2e`. The Playwright image has no poppler and a workflow step is not allowed, so `rendering.sh` installs `poppler-utils` when `CI` is set. `security.sh` also scans `tests/rendering/package-lock.json`. The first CI run on GitHub stays unverified until P15's pipeline runs there. | ADR-042, rule 04 |
