**`frontend/src/features/editor/DraftChips.tsx`** keeps its two exports and imports `./draft-chips.css`:

- `ContactChips({ contacts })` renders nothing for an empty list. Otherwise `<ul className="draft-chips" data-chips="contacts">`, one `<li className="draft-chip" key={contact.id}>` per contact, in order. The caller has already dropped contacts with no text. Each row holds an icon, then the text in a `<span>`. That span has the class `rt-link` only when `contact.url ?? deriveContactUrl(contact.text)` is a URL that passes `isSafeUrl`.
- The icon is an inline `<svg viewBox="0 0 16 16" data-icon={contact.kind} aria-hidden="true" focusable="false">` with a different path for each of the five kinds `email`, `phone`, `location`, `link`, `other`. It is stroked with `currentColor`. No fetched asset and no icon library. The contact's text is not put in the SVG.
- `ItemChips({ items })`: `<ul className="draft-chips" data-chips="items">`, one `<li className="draft-chip" key={item.id}>` per item, holding `<InlineView inlines={item.text} />`. No icon.

**`frontend/src/features/editor/draft-chips.css`**: every length is `calc(var(--pt) * N)`, as in `draft.css`.

- `.draft-chips` wraps with a gap of `--chip-gap`, and `list-style:none`.
- `.draft-chip`: `display:inline-flex`, `align-items:center`, padding `--chip-pad-y` `--chip-pad-x`, background `--chip-fill`, radius `--chip-radius`, `min-width:0`.
- `[data-chips=contacts]`: top margin of 4 pt; font size and line height from `--contact-size` and `--contact-lh`, colour `--contact-color`.
- `[data-chips=items]`: font size and line height from `--list-item-size` and `--list-item-lh`, colour `--list-item-color`.
- The icon is 9 pt square, `flex:none`, with 3 pt between it and the text, with `color:var(--accent)`, `fill:none`, `stroke:currentColor`.
