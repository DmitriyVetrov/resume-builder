## Fixtures and determinism

Use two isolated fictional accounts A and B, separate anonymous and authenticated cookie jars, and a fixed UTC clock. Synthetic addresses use the reserved example.invalid domain and remain only in process memory. Email adapter captures verification/reset tokens in memory, then clears them; optional Mailpit smoke verifies outbox/SMTP delivery without persisting message bodies. Inspect Mongo to confirm one normalized account, SHA-256 token hashes only, session revocation and outbox removal. Use local private Blob/Azurite plus Mongo for the deletion ledger; inject failure in each writer and restart the worker against the same stores.

Clock tests cover just before, exactly at and after verification expiry (24 h), reset expiry (1 h), re-auth age (5 min) and the deletion deadline (24 h). At the expiry instant a token is invalid; older-than-five-minute re-auth is stale. Use no sleeps, real-time expiry waits or silent retries. Concurrent duplicate sign-ups and token redemption run against real persistence. Fresh limiter hosts/partitions check production ADR-038 boundaries: auth-login 10/min/IP plus account back-off after five failures/15 min; auth-email 5/10 min/IP and five messages/hour/address; data-export 3/hour/user. Assert the configured production numbers as well as the 429 boundary.

Capture structured log state, scopes and rendered messages with synthetic markers. Assert absence of address, password, token, cookie, resume and archive markers without printing their values. Browser tests use fresh contexts, block external traffic and do not retain sensitive traces, screenshots or download contents. Reports name operation, status and assertion only; no real contacts, credentials, resume content or bytes.
