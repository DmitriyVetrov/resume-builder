# P05 Acceptance Criteria — Frontend Foundation

P05 proves the shell only. TECHNICAL-SPEC functional requirements for the account, library, editor, rendering and export features keep their full criteria in later phases; structural placeholders here do not count as those features passing. Each Must row has both positive and negative evidence in the Test Architect's plan (ADR-035 B-4).

| ID | Priority / source | Observable pass | Negative case |
|---|---|---|---|
| AC-P05-01 | Must; PHASE.md, ADR-003 | `bash scripts/ci/frontend.sh` exits 0: exact locked install, lint, strict typecheck, Vitest and production build; the built SPA starts with Vite preview independently | Deliberately broken import/type or unavailable backend must not be hidden by a false green build; shell renders with backend unavailable |
| AC-P05-02 | Must; ADR-003/ADR-050, NFR-05 | Root/library and editor shell URLs render their intended page; internal links navigate; browser back/forward and direct deep-link refresh work in preview | Unknown URL renders a labelled not-found view with a working home link, not a blank page or editor |
| AC-P05-03 | Must; PHASE.md, FR-EDT-01/07 layout direction | At 1280 px the editor shell has distinguishable section, edit and preview regions; at 390 px its reachable panel navigation exposes Sections, Edit, Preview and Design placeholders without horizontal page overflow | Keyboard-only user can reach and switch every narrow-screen panel; hidden panels do not trap focus |
| AC-P05-04 | Must; PHASE.md, NFR-06 | Shell has semantic landmarks, page heading, visible focus, labelled navigation and controls; axe WCAG 2.1 A/AA scan finds no violations in shell routes; QA completes keyboard and 200% zoom smoke | A missing label or keyboard trap fails the automated/manual check; recovery and not-found views remain reachable without a pointer |
| AC-P05-05 | Must; PHASE.md, NFR-09 | A routed component error shows a safe message and a working recovery action; no stack, resume content, contact data or token is shown or logged by the boundary | Forced render failure does not leave a blank app or expose the thrown message; normal navigation does not show an error view |
| AC-P05-06 | Must; ADR-006/ADR-040, PHASE.md | TypeScript API types regenerate from the frozen OpenAPI into an ignored folder before typecheck/test/build; a typed same-origin fetch wrapper compiles; shell builds and navigates with no backend or API call | No hand-written divergent DTO, invented endpoint, external tracking request, CDN asset or fabricated working save/export action |
| AC-P05-07 | Must; P05-OBL-P03-02, ADR-042 | A frontend-local multi-stage web image builds from digest-pinned bases, serves the SPA as non-root, answers direct deep links, and passes an OSV image scan in the P05 suite | Image build/scan failure or root runtime is a failure; a direct deep link must not return a static-server 404 |

The three existing Playwright browser engines provide the P05 smoke evidence. NFR-05's latest-two-version production browser matrix is completed in P14; P05 records any engine-specific failure and does not claim full matrix coverage. NFR-02 load timing, FR-EDT-01 live preview, FR-EDT-07 complete phone functionality, and WCAG 2.1 AA for the *finished editor* remain later-phase obligations. Shared Compose/CI/image-lock wiring for the web image is a coordinator integration follow-up after P04/P05 converge (DD-P05-06), outside this parallel source slice.
