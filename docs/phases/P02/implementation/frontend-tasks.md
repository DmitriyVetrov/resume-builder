# Frontend Tasks

P02 has **no frontend implementation tasks** and the Frontend Developer is not dispatched (PD-P02-01). P02 changes no file under `frontend/`.

## Frontend tasks created by the P02 contract (for P05 and later)

These are work orders for the phases named in the "Phase" column. That phase's Solution Architect turns each row into tasks with tests in its own plan, and its Test Engineer writes the tests first. Generated files are never committed or edited; a needed contract change goes through phase-plan §9.1. Section references (§n) point to `../architecture/phase-plan.md`.
