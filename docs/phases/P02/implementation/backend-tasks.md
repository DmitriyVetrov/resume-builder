# Backend Tasks

P02 has **no backend implementation tasks** and the Backend Developer is not dispatched (PD-P02-01). P02 changes no file under `backend/`.

## Backend tasks created by the P02 contract (for P04 and later)

These are work orders for the phases named in the "Phase" column. That phase's Solution Architect turns each row into tasks with tests in its own plan, and its Test Engineer writes the tests first. The contract is read-only for developers: a needed change goes through phase-plan §9.1. Section references (§n) point to `../architecture/phase-plan.md`.
