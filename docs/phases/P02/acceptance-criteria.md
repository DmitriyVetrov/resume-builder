# Acceptance Criteria

Contract approved; mock usable; all P04-P14 API surfaces have planned extension process.

List requirement IDs and observable pass/fail criteria.

## P02 criteria

Paths are relative to the repository root. "The contract" is `contracts/openapi/openapi.yaml`. "§n" refers to `docs/phases/P02/architecture/phase-plan.md`. "Negative" names the in-memory mutation of the contract that must make the check fail (kickoff §3); every Must criterion with a negative case needs both the positive and the negative result recorded in `tests/test-results.md`.
