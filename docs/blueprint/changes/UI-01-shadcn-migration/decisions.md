| DD-UI-11 (`DELEGATED-DEFAULT`) | The theme's `--input` border is too light for WCAG 1.4.11 on text fields; legacy CSS used `#697b8b`. | **`--color-control-border` = `color-mix(in oklab, var(--foreground) 50%, var(--background))`,** applied at the usage sites (`CONTROL`, `SELECT`, rich-text frame). | DD-UI-12 (`DELEGATED-DEFAULT`) | Focus return after a Radix modal dialog. Radix returns focus to its trigger in a later task; these dialogs have no trigger, and P06–P12 tests expect the opener focused as soon as the dialog closes. | **A `ReturnFocus` child inside the content focuses the opener in its unmount cleanup**, which runs after Radix removes its focus trap and before the effects of whatever replaced the dialog, so an effect that moves focus on purpose (Undo, a status line) still wins, as with the native dialog. `onCloseAutoFocus` is prevented. | ADR-053 §4 |
| DD-UI-13 (`DELEGATED-DEFAULT`), test change | `account.spec.ts` "P06 twelve synthetic visual states" finds the page `h1` by role while the deletion dialog is open. The native modal made the page `inert`, which Playwright's role query ignores; the Radix modal sets `aria-hidden` on it, which the query honors. Both hide the page from assistive technology. Options: (a) a non-modal Radix dialog, losing the hidden background, (b) `includeHidden: true` for that one state. | **(b),** only for `deletion-dialog`. The assertion (the heading is rendered and visible for the capture) is unchanged; the other five states keep the accessible-name query. | ADR-053 §4 |
| DD-UI-14 (`DELEGATED-DEFAULT`) | Two timing effects of the shadcn classes made axe read low contrast: `transition-all` faded a button's opacity for 150 ms after `disabled` cleared, and the dialog's 100 ms zoom/fade-in. | **Buttons transition colors only; the dialog content has `duration-0`.** The native dialog and legacy buttons had neither effect. Buttons keep the legacy 46 px minimum and compact controls an explicit `44px`: a box of exactly 44 px (`min-h-11`) reads 43.99999 px in Firefox at a fractional position. | NFR-06 |
| DD-UI-15 (`OWNER`), test change | The owner reported the dark 3 px outline (DD-UI-06), drawn 3 px outside the shadcn lime ring, as a defect: focus must look as in the tweakcn theme. Options: (a) a single 3 px ring in a darker green with ≥ 3:1, (b) exactly the theme ring, (c) the theme ring on fields only. The operator recommended (a). | **(b), owner's choice, superseding DD-UI-06.** `--color-focus` is the theme ring (`--ring` at 50 %); the global `:focus-visible` outline moves into `@layer base` with no offset, so shadcn primitives show only their `ring-3 ring-ring/50` and every other focusable element gets the same ring as an outline. Accepted exception: the ring is below the WCAG 1.4.11 3:1 contrast. Approved test change: `account.spec.ts` (P06 login focus) asserts the 3 px ring spread instead of a ≥ 3 px outline, and `design.spec.ts` (Y09) accepts an outline or that ring. | Owner, 2026-11-08; ADR-053 Amendment 1 |

For dates the operator offered (a) a month popover, (b) the two fields kept, the month as a shadcn Select; the owner chose (b). | **The new-york style** (`components.json`), its button, input, card, dialog, dropdown-menu, badge and skeleton re-added and `select` added; `native-select` removed. Buttons and fields are 36 px (`h-9`), compact row actions the theme's `sm` (32 px), labels 14 px medium, fields 1 px `border-input` with `shadow-xs`; the rich text field and the Text options disclosure follow the same look. Every `<select>` is the theme Select (supersedes DD-UI-07 for `<select>`); month and year stay two fields. Delegated part: below the desktop layout (< 1024 px) controls keep 44 px targets, as the compact editor controls already did. Accepted exceptions: field borders are 1.31:1 against the background (WCAG 1.4.11), and desktop targets are 32–36 px (WCAG 2.5.8 AA, 24 px, still holds). Approved test change, with unchanged assertions: options are chosen through `frontend/src/test/select.ts` and `tests/e2e/select.ts` instead of `change`/`selectOption`, and read by `data-value`, which the trigger and options carry for that; `setup.ts` stubs `scrollIntoView` and pointer capture for Radix in jsdom; `library.spec.ts` E04 asks 44 px below 1024 px and 32 px above. | Owner, 2026-11-09; ADR-053 Amendment 2 |
